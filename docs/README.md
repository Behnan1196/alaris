# Alaris ürün belgeleri

Son güncelleme: 26 Kasım 2026 · Durum: mockup aşaması bitti, geliştirme başlamadı.

Bu klasör Alaris için tek doğru kaynaktır. Mockup'lar görsel referanstır; mockup ile belge çelişirse **belge geçerlidir**, çelişki de `10-acik-sorular.md` dosyasına yazılır.

## İşaretler

- **[KARAR]**: Kullanıcının onayladığı karar. Değiştirmek için kullanıcıya sorulur.
- **[VARSAYIM]**: Belgeyi yazarken yapılan, henüz onaylanmamış tahmin.
- **[AÇIK SORU]**: Cevabı bekleniyor; ayrıntısı `10-acik-sorular.md` içinde.
- **[MVP]** / **[SONRA]**: İlk sürümde olup olmadığı.
